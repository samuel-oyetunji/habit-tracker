# Habit Tracker

A single-page, self-contained habit tracker you can open in any browser. Track daily habit
stacks, check them off as you complete them, edit the text of any step, and drag to reorder
habits or whole stacks to match how your day actually goes.

Created by **Samuel Oyetunji (Samtech)**.

## Features

- **Habit stacks** — group related habits together (e.g. a morning routine) instead of one
  flat list.
- **Daily completion tracking** — checkboxes reset automatically each new day, based on the
  date, with no manual reset needed. Past completions stay stored.
- **Fully editable** — click any habit's text to rename it, add new steps or stacks, delete
  what you don't need.
- **Drag and drop** — reorder habits within a stack, or reorder whole stacks, using the ≡
  handle, so the tracker adapts to your current routine instead of locking you into a fixed
  order.
- **No build step, no dependencies** — it's one HTML file with inline CSS and JavaScript.
  Open `index.html` directly, or host it anywhere that serves static files.

## Usage

1. Download or clone this repository.
2. Open `index.html` in any modern browser (double-click it, or host it on GitHub Pages /
   any static host).
3. Start checking off your habits. Your data is saved in your browser's local storage, so
   it persists between sessions on that browser/device.
